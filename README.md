# Todo List Website

A modern, feature-rich todo list website built with HTML, CSS, and JavaScript.

## Features

- ✅ **Interactive Checkboxes**: Click checkboxes to mark todos as complete
- ✅ **Add & Delete Todos**: Add new todos and delete individual items
- ✅ **Delete All**: Bulk delete all todos with confirmation
- ✅ **Data Persistence**: Automatic saving to browser localStorage
- ✅ **Statistics Dashboard**: Track total, completed, pending tasks and completion rate
- ✅ **Multi-Section Navigation**: Home, Stats, Settings, and About sections
- ✅ **Theme Switching**: Colorful, Dark, and Light themes
- ✅ **Export/Import**: Backup and restore your todos
- ✅ **Smooth Animations**: Page load, hover effects, and transitions
- ✅ **Responsive Design**: Works on all device sizes

## Navigation

- **Home**: Add and manage your todos with checkboxes
- **Stats**: View your productivity statistics and progress
- **Settings**: Change themes and manage data (export/import/clear)
- **About**: Learn about the app features

## How to Use

1. **Add Todo**: Type in the input field and click "Add" or press Enter
2. **Complete Todo**: Click the checkbox next to any todo item
3. **Delete Todo**: Click the "Delete" button next to each item
4. **Delete All**: Click the red "Delete All" button to clear everything
5. **View Stats**: Navigate to Stats to see your progress
6. **Change Theme**: Go to Settings and click theme buttons
7. **Export Data**: Download your todos as JSON file
8. **Import Data**: Upload a previously exported JSON file

## Animations Included

- **Page Load**: Header slides in, content fades up, background shifts
- **Add Todo**: New items bounce in with animation
- **Delete Todo**: Items fade out smoothly before disappearing
- **Hover Effects**: Buttons and items scale and lift on hover
- **Checkbox Toggle**: Visual feedback when checking/unchecking
- **Navigation**: Active states and smooth scrolling
- **Theme Changes**: Smooth transitions between themes

## Data Management

- **Automatic Saving**: All changes are saved instantly
- **Local Storage**: Data persists between browser sessions
- **Export**: Download todos as JSON for backup
- **Import**: Restore todos from JSON backup
- **Clear Data**: Permanently remove all data and settings

## Themes

- **Colorful** (Default): Vibrant gradients and colors
- **Dark**: Sleek dark theme for low-light environments
- **Light**: Clean light theme for bright environments

## How to Run

1. Open `index.html` in your web browser
2. Or use a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## Files

- `index.html` - Main HTML structure with navigation and sections
- `styles.css` - CSS with themes, animations, and responsive design
- `script.js` - JavaScript with all functionality and data management
- `styles.css` - CSS styling with colorful gradients and animations
- `script.js` - JavaScript functionality with local storage and animations
